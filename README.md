# Smart College Portal Management System

A web-based application for managing student academic activities digitally.

## Features

- Admin, Student, and Faculty modules
- Attendance management
- Result management
- Assignment submission
- Notice board
- Secure authentication

## Technologies

- Backend: Python Flask
- Database: SQLite
- Frontend: HTML5, CSS3, JavaScript, Bootstrap

## Installation

1. Install Python
2. Create virtual environment: `python -m venv venv`
3. Activate venv: `venv\Scripts\activate`
4. Install dependencies: `pip install -r requirements.txt`
5. Run the app: `python app.py`
6. Open browser: http://127.0.0.1:5000

## Sample Credentials

- **Admin**: admin@example.com / admin
- **Student**: john@example.com / password
- **Faculty**: alice@example.com / password

## Usage

- Admin login with default credentials
- Manage students, faculty, departments
- Students can view attendance, results, submit assignments
- Faculty can mark attendance, upload results, notes
